### 🔍 Key Security Projects & Assessments

#### 1. Critical Broken Access Control & Sensitive PII Exposure (Responsible Disclosure)
* **Target Type:** Institutional Web Portal *(Anonymized per Responsible Disclosure Policy)*
* **Vulnerability:** Broken Access Control / Unauthenticated Sensitive Data Exposure (OWASP A01:2021)
* **Impact:** Identified unauthorized exposure of student identification cards, personal records, and faculty credentials.
* **Deliverables:** Authored a comprehensive CVSS-scored VAPT report with step-by-step reproduction, video Proof-of-Concept (PoC), and access control remediation guidelines.

#### 2. Safe Buffer Overflow Proof-of-Concept (PoC) Modeling
* **Focus:** Memory Corruption & Stack-Based Buffer Overflow Analysis
* **Methodology:** Evaluated memory handling risks during a bug bounty assessment. Strictly adhering to ethical hacking Rules of Engagement (RoE), built an **isolated local C program** to safely demonstrate stack buffer overflow mechanics (`strcpy` / return address overwrite) and mitigation techniques (`strncpy`, ASLR, Stack Canaries) without impacting production systems.

#### 3. Web Application Vulnerability Assessments (SQLi & XSS)
* **Tools Used:** Burp Suite, OWASP ZAP, Nmap
* **Findings:** Identified and documented SQL Injection (SQLi) and Cross-Site Scripting (XSS) vectors across test web applications, providing parameterized query and input sanitization fixes.

#### 4. Network Traffic Analysis & Packet Inspection
* **Tools Used:** Wireshark
* **Focus:** Monitored live network traffic and PCAP captures to analyze HTTP/HTTPS protocols, detect anomalous requests, and document network security findings.
